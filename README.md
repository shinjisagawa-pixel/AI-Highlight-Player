## How to add a new talk
1. Create: `talks/YYYY-MM-your-slug/index.html`
2. Update inside the file:
   - `<title>` / heading
   - `<audio>` MP3 URL
   - `segments` timestamps
3. Add a new card to the Library `index.html`
